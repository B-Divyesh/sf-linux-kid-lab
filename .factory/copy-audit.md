# Copy audit — Linux Kid Lab 1.0.4

Audited 29 August 2026. This record covers every landing-page heading,
sentence, button, fact, and footer sentence, plus every README sentence and
bullet. Dynamic activity titles are labels. Activity instructions are direct
imperatives rather than marketing copy.
